# Historical Seed Cases

This directory will hold **structured, source-backed fixtures** for historical replay and development.

Do not add a case as a bare accusation. Each case fixture should include:
- canonical entity and aliases;
- jurisdiction;
- scheme/category;
- dated observations;
- source tier;
- extracted claims;
- verified regulatory/enforcement events;
- lifecycle stages;
- activated indicators by date;
- final known outcome;
- uncertainty notes.

Historical replay must only expose evidence available on or before the simulated date.

The first research tranche should reconstruct approximately 20 significant Kenyan mass-recruitment fraud/scam cases deeply enough to test Dawnwatch's warning lead time.
